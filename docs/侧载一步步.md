# 侧载「清账」到 iPhone（Windows 全程）

> 前置：GitHub 仓库已建好、Actions 已打出 IPA。
> 需要的两个安装包我已经放在**桌面**：`iTunes64Setup.exe`、`SideloadlySetup64.exe`

## 一、装驱动和工具

1. **装 iTunes**（不是 Microsoft Store 版，必须是苹果官网版）
   - 双击桌面的 `iTunes64Setup.exe` → 一路下一步
   - 装完**不用打开 iTunes**，它只是把「Apple Mobile Device 服务」装上
   - 装完拔插一次数据线
2. **装 Sideloadly**
   - 双击 `SideloadlySetup64.exe` → 下一步到完成
3. **iPhone 连线并信任**
   - 数据线连电脑 → 手机上点「信任」→ 输锁屏密码

## 二、把 IPA 装进去

1. 打开 Sideloadly
2. 左上 **IPA** 图标 → 选下载好的 `qingzhang-unsigned.ipa`
3. **Apple ID** 一栏填你的 Apple 账号（`xxx@icloud.com` 或注册用的邮箱）
4. 点 **Start**
5. 会弹框要**双重认证验证码**：在 iPhone 上弹的「Apple 登录请求」里点允许，把 6 位数字填进去
6. 等待进度跑完（1–3 分钟），提示 **Done**

## 三、手机上收尾

1. 桌面出现「清账」（可能先在「App 资源库」里）
2. 第一次点开若提示「未受信任的开发者」：
   **设置 → 通用 → VPN 与设备管理 → 开发者 App → 你的 Apple ID → 信任**
3. 打开「清账」，应该直接看到示例账目

## 四、验证自动记账

1. 「快捷指令」→ 新建 → 添加操作「打开 URL」→ 填：
   `qingzhang://add?amount=12&category=餐饮&note=午餐`
2. 运行 → 清账弹「已自动记账 · 餐饮 12.00 元」
3. 绑定「轻点背面两下」：设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下

## 五、常见问题

| 提示 | 原因与处理 |
| --- | --- |
| `No device found` / 设备列表空的 | iTunes 没装或没装对（必须是官网版）；拔插数据线；手机重新点「信任」 |
| `Please sign in with your Apple ID` / `Invalid anisette` | Apple ID 或密码错；先退出 Sideloadly 重开；iTunes 版本太旧就更新 |
| 安装到一半 `maximum number of apps` | 免费账号同时只能签 3 个自签 App，删掉一个旧的 |
| `The application is missing ...` 或黑屏闪退 | 确认手机 ≥ iOS 15；重新用 Sideloadly 装一次 |
| 7 天后图标点不开 | 正常，免费签名过期；重新在 Sideloadly 里 Start 一次即可 |
| 收不到验证码 | 在 iPhone 上：设置 → 你的名字 → 密码与安全性 → 获取验证码 |
